Fixed-template character test

The shirt uses the original character pixels within a fixed outline. Color changes cannot drift in size or position. The hair is separately fitted and clipped. This is an experiment, not the finished app.

Shirt colors

Gray and colored shirts share the same source and silhouette. Different garment cuts, more hairstyles, expressions, and other body options still need fitted templates. Check the neck, sleeves, hairline, and edges for visible seams.
