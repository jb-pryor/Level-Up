# Long hair with visible original ears

`chestnut.png` was generated using the built-in image-generation tool. Original bald female/male reference bases were left untouched. Runtime SVG transforms fit this shared PNG separately to the two head shapes, with brown/black/blonde/gray tint options. Rear texture backing fills the ear region; the front pass lays the crown and long locks over the base; AvatarEars restores original ear pixels above the front hair. No skin is baked into this texture.

Final prompt used:
Create a production game avatar HAIR ONLY PNG asset on a transparent background. References show the style and head shapes; DO NOT include either person, face, skin, ears, neck, clothes or body. A single front-facing long chestnut brown hairstyle, softly wavy, center part, tucked behind both ear positions, hair reaching upper chest. Friendly polished 3D cartoon render matching the references, detailed sculpted strands and soft highlights. The complete wig silhouette should occupy most of a square image with small margins: rounded crown at top, transparent large central face opening below the hairline, narrow side sections sweep outward behind the expected ears, long locks descend on both sides, transparent space between locks. Both ear areas must be transparent so the ORIGINAL avatar's ears show, with no fake ears painted into hair. No bangs over eyes, no skin, no text, no mannequin, no checkerboard. The asset will be fitted to both heads using separate transforms and layered behind the ears.
